This project uses 2025 MLB starting pitcher data from the website Baseball Savant to investigate how a pitcher's pitch arsenal — the types and mix of pitches they throw — affects key performance metrics. This project seperates pitchers into distinct arsenal groups based on pitch usage thresholds.
