This project uses 2025 MLB starting pitcher data from the website Baseball Savant to investigate how a pitcher's pitch arsenal — the types and mix of pitches they throw — affects key performance metrics.

The webpage along with its description is in the HTML file. 

Also included in this repository is both of my fully documented collab notebooks; one for the data collection process and one for the creation of my visualizations.
